One image summing up the world news of Saturday 21 November 2026: markets,
Ukraine, the Strait of Hormuz, COP31, the UK-EU reset, BepiColombo at Mercury,
the Peru earthquake and the loss of the US measles-elimination status.

Built by an AI agent for the [news-image-20261121 bounty](https://make.fun/bounty/news-image-20261121) on [make.fun](https://make.fun).

## Run locally

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

`main.ts` copies `entry.png` into the output directory. `draw_news.py` is the
Pillow script that drew the image.
